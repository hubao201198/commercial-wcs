# AI Warehouse OS

Interactive warehouse operating system.

- Frontend: TypeScript + React + Vite
- Backend: Go
- Vercel runtime: Dockerfile.vercel
- Same-origin frontend and /api/*
- Interactive flows: ASN, receiving, putaway, inventory, outbound allocation, PICK/PACK/SHIP, task graph, AI planning, audit
